## [0.1.0] - 2026-08-25

### Added

- GitHub App webhook and Checks integration with least-privilege permissions.
- PostgreSQL data model for organizations, installations, repositories, policies, scans, findings,
  exceptions, artifacts, and audit events.
- Redis/BullMQ scan orchestration with retry and concurrency controls.
- Static secret, Dockerfile, GitHub Actions, npm, and Python dependency analysis.
- OSV batch vulnerability lookup with remediation metadata.
- Policy enforcement, expiring exceptions, stable fingerprints, and manual scan retry.
- JSON, SARIF 2.1.0, and CycloneDX 1.6 exports.
- Responsive operations dashboard and safe vulnerable demonstration repository.
- Docker Compose deployment, schema migration, CI, security policy, and operator documentation.
